README
======

Yeh folder do Node.js scripts par mushtamil hai. Dono scripts "readline" module
use kar ke terminal se user input lete hain aur switch-case ke zariye output
dikhate hain.

----------------------------------------
1) code1_subject.js
----------------------------------------
Kaam:
- User se subject number poocha jata hai (1 se 5 tak).
- 1 = Math
- 2 = Physics
- 3 = Chemistry
- 4 = Urdu
- 5 = English
- Koi aur number dalne par "invalid input" show hota hai.

Chalane ka tareeqa:
    node code1_subject.js

----------------------------------------
2) code2_role_department.js
----------------------------------------
Kaam:
- Pehle user se "role" poocha jata hai:
    1 = Employee
    2 = Admin
    3 = Supervisor
- Phir "department" poocha jata hai:
    1 = IT
    2 = HR
    3 = Management
- Role aur department dono ke combination ke hisab se message print hota hai,
  jaise: "Employee -> IT department".
- Agar role ya department invalid ho to "Invalid role" ya
  "Invalid department" show hota hai.

Chalane ka tareeqa:
    node code2_role_department.js

----------------------------------------
General Requirements
----------------------------------------
- Node.js installed hona chahiye computer par.
- Terminal/CMD mein us folder mein jayen jahan yeh files hain, phir upar diye
  gaye command se run karen.
- Dono scripts interactive hain, yani script chalne ke baad terminal mein
  aapko sawal poocha jayega aur aap type kar ke jawab denge.
